# Mở Khóa Chuyển Đổi landing page

Static landing page drafts for Vũ Kim Khánh's free workshop.

- `index.html`: original full-page design.
- `index-variant-b.html`: warmer section rhythm and structured content blocks.
- `index-variant-c-plum.html`: smoky plum palette and softer champagne transition.
- `compare.html`: original versus variant B.
- `compare-b-c.html`: variant B versus smoky plum.
- `palette-options.html`: color study for the two purple directions.

The image files used by the pages are in `assets/`. The registration form is a disabled visual placeholder. The Cloudflare deployment bundle is generated separately and is not tracked here.
